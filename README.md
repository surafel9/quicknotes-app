# QuickNotes

QuickNotes is a simple and clean note-taking web application built from scratch to help you capture your thoughts instantly. It provides an intuitive interface to organize notes into categories and automatically saves your data directly to the browser.

## Features
- Add new notes and assign them to categories (Personal, Work, Study).
- Notes are styled cleanly and responsive on mobile devices.
- Search your notes in real-time.
- Delete individual notes or clear all notes at once.
- Validates note length (up to 200 characters) and prevents empty inputs.
- Automatically saves and loads notes via localStorage so your data is never lost.

## How to run locally
1. Clone this repository or download the source code.
2. Open the `index.html` file in any modern web browser.
3. No server or build tools are required!
